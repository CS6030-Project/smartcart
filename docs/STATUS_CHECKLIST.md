# What you can safely claim at submission

Check each item against real evidence before changing the report.

- [ ] GitHub organization and repository created by the team.
- [ ] Initial starter files committed and visible in repository.
- [ ] GitHub Actions 'Starter CI' run shows a green check on the main branch.
- [ ] Team members invited / accepted invites.
- [ ] Local PostgreSQL container starts (optional tonight).
- [ ] Spring Boot API endpoint runs (not included in starter).
- [ ] Chrome extension loads in browser (not included in starter).
- [ ] GCP/Azure application deployed (not included in starter).

If only the first three pass, say: 'The team has created its shared repository, added the initial Java matching proof of concept and contract examples, and configured GitHub Actions to run starter tests. Full API, extension, cloud deployment and real-product evaluation are planned next.'

Repository URL to paste into report ONLY AFTER you create and verify it: https://github.com/CS6030-Project/smartcart (adjust if you pick a different organization or repo name).
